# Historical demo audio

maple-leaf-rag.ogg is a 53-second excerpt of Scott Joplin’s Maple Leaf Rag, recorded by Foil Fencer2 (2007), identified as public domain in the original demo. Source: https://commons.wikimedia.org/wiki/File:Maple_Leaf_Rag.ogg

fixture.mp3 is the original synthetic test tone fixture. These historical assets are retained for the source/demo tests and excluded from the npm package. The npm examples/audio samples are eight-second public-domain piano excerpts from Maple Leaf Rag (see examples/audio/NOTICE.md).
