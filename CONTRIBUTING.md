# Support and issue reports

SoundForge accepts issues, including bug reports, feature requests, and documentation problems:

https://github.com/pahooper/soundforge/issues

**Pull requests are not accepted.** Please open an issue before spending time on a proposed change. This applies to code, documentation, and dependency updates.

For a useful bug report include:

- The SoundForge version (`npm ls @pahooper/soundforge`) and CLI version (`npx --no-install soundforge-analyze --version`).
- Browser and operating system; Node version for preprocessing.
- The smallest HTML or catalog that reproduces the problem.
- Steps to reproduce, expected behavior, actual behavior, and relevant browser/terminal errors.
- For decoding problems, the container, codec, and a non-sensitive audio sample you have permission to share.

Do not include passwords, tokens, private catalogs, or recordings you cannot share publicly.
